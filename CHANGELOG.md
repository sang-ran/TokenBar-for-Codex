# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0-alpha] - 2026-07-30

### Added

- Live token monitoring for the active Codex task
- Input, cached-input, and output token breakdown
- Subscription quota display through the Codex read-only app server
- Automatic token-only mode for API-key accounts
- One-line and two-line menu-bar layouts
- Low-quota warning colors and launch-at-login option
- Native Apple Silicon application packaging
- Responsive listener status and sub-second token polling
